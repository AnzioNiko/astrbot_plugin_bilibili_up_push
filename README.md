# B站UP更新订阅

B站UP更新订阅是一款面向群聊的 B 站投稿通知插件。订阅 UP 主后，插件会定时检查其最新投稿，并在订阅所在的群推送视频标题、发布时间、简介和链接；也可以调用万能解析器获取视频文件并一并发送。

插件名称：`astrbot_plugin_bilibili_up_push`

插件列表显示名称：B站UP更新订阅

## 功能

- 按群独立保存 UP 主订阅，互不影响。
- 每 15 分钟检查一次 UP 主的最新投稿。
- 支持使用 UP 主 UID 或昵称订阅。
- 推送视频标题、发布时间、简介和视频链接。
- 可选发送视频文件，需要安装并启用万能解析器。
- 支持立即测试推送链路，不修改已有订阅。
- 首次订阅只记录当前最新视频，不补发历史投稿。

## 安装

### 安装前准备

1. 确保 AstrBot 可以正常加载本地插件。
2. 准备 AstrBot 管理员账号，用于私聊执行 B 站扫码登录。
3. 如果需要推送视频文件，建议同时安装并启用万能解析器。

### 通过插件压缩包安装

将插件打包为 ZIP 时，压缩包内应保留插件根目录，例如：

```text
astrbot_plugin_bilibili_up_push.zip
└── astrbot_plugin_bilibili_up_push/
    ├── main.py
    ├── metadata.yaml
    ├── _conf_schema.json
    ├── requirements.txt
    └── README.md
```

在 AstrBot 的插件管理中安装该压缩包，安装完成后重载插件或重启 AstrBot。

### 手动安装

将整个插件目录放入 AstrBot 数据目录下的 `plugins` 目录：

```text
<AstrBot 数据目录>/plugins/astrbot_plugin_bilibili_up_push/
```

插件目录名必须保持为 `astrbot_plugin_bilibili_up_push`，不要只复制 `main.py` 或修改元数据中的插件名称。

### 安装依赖

AstrBot 会在安装或载入插件时根据 `metadata.yaml` 和 `requirements.txt` 自动尝试安装以下 Python 依赖：

| 依赖 | 用途 | 是否必需 |
| --- | --- | --- |
| `aiohttp` | 请求 B 站接口、轮询扫码状态和发送推送 | 必需 |
| `segno` | 生成 B 站登录二维码 | 必需 |

通常无需手动执行 `pip install`。如果插件日志提示缺少依赖，请在插件目录中使用 AstrBot 自带的 Python 环境执行：

```bash
pip install -r requirements.txt
```

安装完成后重新载入插件。插件列表中出现“B站UP更新订阅”即表示安装成功，也可以在聊天中发送 `/UP推送帮助` 验证。

## 可选依赖

### 万能解析器

视频文件推送依赖 `astrbot_plugin_parser`（万能解析器）。万能解析器属于可选依赖，仅在开启“推送时发送视频文件”时需要。

使用视频文件推送前需要满足：

1. 安装并启用万能解析器。
2. 万能解析器版本包含 PR #223 提供的公开 `parse_url` 接口。
3. 在万能解析器设置中启用 B 站解析器。
4. 按需要配置万能解析器的 B 站登录态、视频清晰度、视频编码、时长限制和大小限制。

启用了视频文件推送但没有安装万能解析器时，插件仍会发送视频文字通知，并额外发送一条视频文件处理失败的原因。

如果不需要视频文件，可以在本插件设置中关闭“推送时发送视频文件”，此时只推送文字和链接，不需要安装万能解析器。

### 万能解析器的 B 站登录态

万能解析器的 B 站登录态与本插件的 B 站登录态相互独立：

- 本插件的登录态用于搜索 UP 主、读取空间投稿和检测新视频。
- 万能解析器的登录态用于下载 B 站视频文件。
- 需要 1080P 高码率、1080P+、4K、8K、HDR 或杜比等高画质时，请在万能解析器中配置具有对应权限的 B 站账号。
- 普通公开视频通常可以在万能解析器未登录的情况下解析，但可用画质可能受限。

## 配置

本插件当前提供以下配置：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `send_video_file` | 开启 | 开启后先发送视频信息，再调用万能解析器获取并发送视频文件；关闭后只发送文字和链接。 |

视频清晰度、视频编码、下载超时、文件大小限制、视频时长限制、缓存目录、代理和万能解析器的 B 站登录态均由万能解析器管理。

## 首次使用

### 1. 登录 B 站

由机器人管理员私聊机器人发送：

```text
/B站登录
```

机器人会发送 B 站登录二维码。使用 B 站 App 扫码并在手机上确认登录。二维码有效期约为 3 分钟，过期后重新执行命令即可。

登录完成后发送：

```text
/B站登录状态
```

看到“当前已登录 B 站”即可继续。

注意：

- `/B站登录` 和 `/B站登出` 仅允许机器人管理员使用。
- 登录二维码只能在私聊中生成，不要在群聊中操作。
- 本插件登录态保存在插件数据目录的 `bili_cookies.json` 中，请勿公开该文件。

### 2. 在群内订阅 UP 主

进入需要接收通知的群，发送：

```text
/订阅UP <UP主UID或完整昵称>
```

示例：

```text
/订阅UP 12345678
/订阅UP 某某UP主
```

推荐优先使用 UID。UID 可以从 UP 主空间链接中获取：

```text
https://space.bilibili.com/<UID>
```

使用昵称订阅时，插件要求昵称完全匹配。如果有多个 UP 主使用相同昵称，插件会提示改用 UID。

订阅成功时，插件会记录该 UP 主当前最新视频。之后只推送订阅之后发布的新视频，不会补发更早的投稿。

### 3. 测试推送

在目标群中发送：

```text
/测试UP推送 <UP主UID或完整昵称>
```

插件会立即向当前群发送该 UP 主最新视频的通知，用于检查 B 站接口、消息发送和视频文件解析链路。测试不会新增、删除或修改订阅记录。

如果测试时文字通知正常，但视频文件发送失败，请优先检查万能解析器是否已安装、启用并包含 `parse_url` 接口。

## 指令说明

| 指令 | 使用位置 | 权限 | 说明 |
| --- | --- | --- | --- |
| `/订阅UP <UID或昵称>` | 群聊 | 无额外管理员限制 | 在当前群订阅 UP 主。 |
| `/取消订阅UP <UID或昵称>` | 群聊 | 无额外管理员限制 | 取消当前群对指定 UP 主的订阅。 |
| `/UP订阅列表` | 群聊 | 无额外管理员限制 | 查看当前群已订阅的 UP 主和 UID。 |
| `/测试UP推送 <UID或昵称>` | 群聊 | 无额外管理员限制 | 立即发送最新视频通知，不修改订阅。 |
| `/UP推送帮助` | 群聊或私聊 | 无额外管理员限制 | 查看插件指令摘要。 |
| `/B站登录` | 私聊 | 机器人管理员 | 生成二维码并登录本插件使用的 B 站账号。 |
| `/B站登录状态` | 群聊或私聊 | 无额外管理员限制 | 查看本插件是否已登录 B 站。 |
| `/B站登出` | 私聊 | 机器人管理员 | 删除本插件保存的 B 站登录态。 |

## 推送规则

- 插件启动约 15 秒后进行第一次检查，之后每 15 分钟检查一次。
- 新投稿会先发送文字通知，再按配置决定是否发送视频文件。
- 单次检查会读取 UP 主最近的投稿列表，并按发布时间从旧到新推送尚未通知过的视频。
- 如果旧视频游标已经超出最近读取范围，插件只补发最新一条，避免机器人离线较久后批量刷屏。
- 文字通知发送失败时，插件保留上一次视频游标，下次轮询会重试。
- 文字通知成功后，即使视频文件解析失败，也不会重复发送文字通知；插件会单独发送视频文件处理失败的原因。

## 数据文件

插件运行数据保存在 AstrBot 插件数据目录：

```text
<AstrBot 数据目录>/plugin_data/astrbot_plugin_bilibili_up_push/
```

主要文件：

| 文件 | 说明 |
| --- | --- |
| `subscriptions.json` | 各群订阅的 UP 主、昵称和最新视频游标。 |
| `bili_cookies.json` | 本插件使用的 B 站登录凭据，属于敏感文件。 |

升级、迁移或重命名插件前，建议备份整个插件数据目录。删除该目录会同时丢失所有群订阅和 B 站登录态。

## 常见问题

### 插件列表中没有显示

检查以下项目：

1. 插件目录名是否为 `astrbot_plugin_bilibili_up_push`。
2. `metadata.yaml` 中的 `name` 是否为 `astrbot_plugin_bilibili_up_push`。
3. 是否在 AstrBot 运行期间直接重命名过插件目录。
4. 重新载入全部插件或重启 AstrBot。

在运行期间重命名目录时，AstrBot 可能先卸载旧插件，但不会自动从新目录加载。完整重启后才会重新扫描插件目录。

### 提示“请先私聊机器人使用 /B站登录”

本插件自身的 B 站登录态不存在或已失效。请由机器人管理员私聊执行 `/B站登录`，扫码完成后再重试。

其他 B 站插件的登录状态不会自动共享给本插件，万能解析器的登录状态也不会替代本插件登录。

### 只有文字通知，没有视频文件

依次检查：

1. 本插件的“推送时发送视频文件”是否开启。
2. 万能解析器是否已安装并启用。
3. 万能解析器是否包含 PR #223 提供的 `parse_url` 接口。
4. 万能解析器的 B 站解析器是否启用。
5. 视频是否超过万能解析器的时长或文件大小限制。
6. 插件日志和群内返回的视频文件处理失败原因。

暂时不需要视频文件时，可以关闭“推送时发送视频文件”，只保留文字通知。

### 视频清晰度不够

视频下载画质由万能解析器控制。请在万能解析器中配置 B 站登录态和所需清晰度。B 站会员画质还需要账号本身具有相应权限。

### 无法按昵称找到 UP 主

插件只接受完整昵称，不接受模糊搜索。昵称存在特殊字符、重名或搜索结果被 B 站风控时，请直接使用 UP 主 UID。

### 订阅后没有立即收到历史视频

这是预期行为。首次订阅只记录当前最新视频，之后才开始推送新投稿。需要检查推送效果时使用 `/测试UP推送 <UID>`。

### 修改了 UP 主昵称后无法取消订阅

可以继续使用 UID 取消订阅。UID 不会因为昵称修改而变化。

## 安全说明

- B 站登录二维码和 `bili_cookies.json` 都属于敏感信息，不要发送到群聊、截图或公开仓库。
- 建议仅由机器人管理员执行登录和登出操作。
- 如果登录态可能泄露，请先在 B 站退出相关设备或修改密码，再使用 `/B站登出` 清除本插件登录态并重新扫码。
